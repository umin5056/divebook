DiveBook API 목록 및 개발 현황
(기준: 실제 소스코드, 2026-08-12)

===========================================
인증 (/api/auth)
===========================================
POST   /api/auth/email/send             완료
POST   /api/auth/email/verify           완료
POST   /api/auth/refresh                완료
POST   /api/auth/logout                 완료

===========================================
강습 (/api/lessons)
===========================================
GET    /api/lessons                          완료
POST   /api/lessons                          완료
PUT    /api/lessons/{lessonId}               완료
DELETE /api/lessons/{lessonId}               미구현
  - 취소는 status를 cancelled로 PUT하는 방식으로 대체 구현됨
GET    /api/lessons/{lessonId}/enrollments   완료 (문서에 없던 추가 기능)

===========================================
수강생 (/api/students)
===========================================
GET    /api/students          완료
POST   /api/students          미구현
GET    /api/students/{id}     미구현
PUT    /api/students/{id}     미구현
DELETE /api/students/{id}     미구현

- FE api/student.js도 getStudents() 하나만 호출
- 현재 수강생은 조회만 가능, 등록/수정/삭제는 화면도 API도 없음

===========================================
수업-수강생 배정 (/api/enrollments)
===========================================
PATCH  /api/enrollments/{enrollmentId}/paymentStatus   완료
POST   /api/lessons/{id}/enrollments (수강생 배정)        미구현
DELETE /api/lessons/{id}/enrollments/{studentId} (배정 취소) 미구현

- 현재 더미 데이터(수강생 30명, 강습 30개, 매핑 63건)는
  전부 SQL로 직접 넣은 것이며, 실제 API로는 생성 불가능한 상태

===========================================
강사 (/api/instructors)
===========================================
전체 CRUD   미구현 (컨트롤러는 존재하나 엔드포인트 0개)

- DB에 있는 강사 1건(조우민)도 SQL로 직접 등록한 것
- API로 강사를 등록/조회하는 기능 없음

===========================================
크루
===========================================
경량화 작업으로 완전히 제거됨 (의도된 것)

===========================================
요약
===========================================
동작하는 기능:
  - 로그인 (이메일 인증코드)
  - 강습 목록 조회 / 생성 / 수정 / 취소
  - 강습별 수강생 목록 조회
  - 결제상태 변경
  - 수강생 목록 조회

화면/API 중 한쪽만 있거나 아예 없는 기능:
  - 수강생 등록 / 수정 / 삭제
  - 강사 관리 (등록/조회/수정/삭제)
  - 강습에 수강생 직접 배정
